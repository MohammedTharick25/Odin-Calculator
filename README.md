# Awesome Web Calculator

Welcome to Awesome Web Calculator – your sleek, fully functional, and super responsive calculator built with HTML, CSS, and JavaScript! Perfect for quick calculations, learning purposes, or just showing off some coding skills.

## 🚀 Features

Basic arithmetic: Add, subtract, multiply, divide

Decimal support: Work with floating-point numbers

Clear button (C): Reset everything instantly

Backspace (←): Undo your last input

Keyboard support: Type numbers and operators naturally

Numbers: 0-9

Operators: + - * /

Decimal: .

Equals: Enter or =

Backspace: Backspace

Clear: Escape

Responsive design: Works on desktop and mobile

Footer included: Always stays below the calculator

## 🎨 Design

Modern flat UI with a clean look

Bright operator buttons for clarity

Hover effects on buttons for a tactile feel

Centered layout with footer at the bottom

## ⚙️ How to Use

Open index.html in your favorite browser.

Click buttons or use your keyboard to enter numbers and operations.

Press = or Enter to see the result.

Click C or Escape to clear the calculator.

Click ← or press Backspace to remove the last digit.

## 🛠️ Technologies Used

HTML5 – Structure and semantic elements

CSS3 – Styling, grid layout, and flexbox

JavaScript – Calculator logic and keyboard support

## 💡 Why You’ll Love It

Simple, elegant, and fully functional

Great for learning DOM manipulation and event handling

Works offline – just open it in a browser

Fully customizable – tweak colors, size, or add new features
